# ערכת המותג Strauss Drive (מהמעצבת)

ערכת העיצוב המאושרת: לוגו, קמע, צבעים ("Color in Motion"), רקעים, SVG ו-4 מוקאפים מאושרים.
**היא קובעת איך המסכים נראים. מה מוצג בהם קובע ה-API.**

## ⚠️ לפני שמשתמשים במוקאפים: סגנון כן, תוכן לא

המוקאפים הם תמונות שנוצרו בכלי AI. **הסגנון** מחייב: לוגו, קמע, צבעים, פריסה, כרטיסים, טיפוגרפיה ותחושה.
**התוכן שבתמונות אינו נכון ואסור להעתיק אותו.** כל מספר, רכב, זכאות וטקסט עסקי מגיעים מה-API, לפי המיפוי ב-[`docs/ui/README.md`](../README.md).

## החלטה פתוחה בערכה: אימות זכאות וקבוצת רכב
הערכה מציינת שזו "החלטת מוצר פתוחה". **ב-API היא כבר סגורה, והממשק לא מחליט עליה:**
- הקבוצה נגזרת מהעיסוק לפי טבלת העיסוקים (`api/config/occupations.json`).
- קבוצה שהעובד מסר ולא תואמת לעיסוק, או עיסוק שלא בטבלה ← **שאלה לנציג התחבורה**. לא מנחשים.
- הממשק רק מציג את `eligibility.eligible` ואת `reason` שהמנוע החזיר.

**לא הועתק לריפו** (נשאר בקובץ ה-ZIP של המעצבת):
- מוקאפים ישנים (`legacy`), כי המאושרים מחליפים אותם.
- לוגואים חלופיים.
- גלריית נכסים, שהיא כפילות של התמונות.
- 3 מסמכי מפרט ב-`05_REFERENCE_DOCS`, שכבר נמצאים ב-`docs/ui/` (זהים).
- מסמכי UX ישנים.

## לשימוש במסכים (מפתחת ב׳)
- **מעתיקים ל-`web/public/brand/` רק את מה שבשימוש בפועל**, ומקטינים: לוגו, קמע ראשי, רקע אחד או שניים, SVG. התמונות כאן הן PNG גדולים (כ-1 MB כל אחד). ממירים ל-WebP או AVIF, או משתמשים ב-`next/image`, כדי שהאתר יישאר מהיר.
- רקעים וקישוטים **לעולם לא מאחורי מספרים, גרפים או טפסים**. כך גם ההנחיה של המעצבת.
- RTL ונגישות: לקמע ולקישוטים `alt=""` (דקורטיביים). ניגודיות צבעים לפי AA.
