Key regions:

- center chat conversation area

## Screen 3 — Comparison / result screen
Reference: `03_MOCKUPS/approved/03-comparison-results-screen.png`

Purpose:
- show the recommended vehicle option and financial comparison

Key regions:
- left narrow chat/support panel
- central featured result card
- major monthly net delta block
- 2 secondary net values
- waterfall / explanation chart
- bottom benefit summary row

## Screen 4 — Representative dashboard
Reference: `03_MOCKUPS/approved/04-representative-dashboard.png`

Purpose:
- operational interface for open employee questions

Key regions:

- selected request detail in the center
- status / SLA chips
- editable response form
