## איך זה נמדד
כל שיחה רצה דרך אותו `TurnService` שה-API משתמש בו, מול שרשרת המודלים האמיתית (המכסה החינמית). כל הבדיקות **דטרמיניסטיות** ומחושבות ממה שקרה בפועל: הפרופיל שנשמר, הכרטיסים שהוצגו, ה-trace של הכלים. אין מודל ששופט מודל. השיחות 1-6 הן ששת העובדים של האתגר עם השאלה מגיליון האתגר, וההפרש הצפוי הוא המספר מגיליון הייחוס. כל הנתונים פיקטיביים. התוצאות נשמרות לכל שיחה ב-`evals/runs/`, כך שהרצות מימים שונים (בגלל המכסה) מצטרפות לדוח אחד. הרצה מחדש: `cd api && uv run python -m evals.run_evals` (או מספרי שיחות).
