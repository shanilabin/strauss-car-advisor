# מסד הנתונים (Supabase)

| קובץ | מה |
|---|---|
| `migrations/*.sql` | מבנה מסד הנתונים: טבלאות, הרשאות (RLS), זמן אמת. רץ לפי הסדר |
| `scripts/grant_rep_role.sql` | נותן למשתמש `rep@demo.local` את תפקיד הנציג (פעם אחת) |
| `tests/rls_test.sql` | בדיקת הרשאות: 18 בדיקות, הכול מתבטל בסוף ולא נשאר כלום |
| `tests/run_local.py` | מריץ את המיגרציות ואת בדיקת ההרשאות על Postgres זמני במחשב (וגם ב-CI) |

## להחיל על הפרויקט ב-Supabase (פעם אחת, בעלת הפרויקט)

```bash
npx supabase login
```
נפתח דפדפן ← מאשרות.

```bash
npx supabase link --project-ref ruiurtawpinejuicgnxx
```
יבקש את סיסמת מסד הנתונים (Database Password ממנהל הסיסמאות). מקלידות אותה בטרמינל, לא בצ'אט.

```bash
npx supabase db push
```
מציג את המיגרציות שיוחלו ← מאשרות (`Y`).

אחר כך ב-Supabase ← **SQL Editor** ← New query:
1. מדביקות את `scripts/grant_rep_role.sql` ← Run. אמורה לחזור שורה: `rep@demo.local | rep`.
2. מדביקות את `tests/rls_test.sql` ← Run. אמורות לחזור **18 שורות, כולן `passed = true`**.

## טעינת מאגר רשות המסים (77,988 שורות)
פעם אחת, וכל פעם שמגיע קובץ חדש. דורש את `api/.env.local` עם `SUPABASE_URL` ו-`SUPABASE_SECRET_KEY`.

```bash
cd api
uv run python -m strauss.ingest.load_value_of_use --csv ../data/source/value-of-use-2026.csv
```
- קודם כל השורות נקראות ונבדקות. אם יש שורה פגומה, **שום דבר לא עולה**, וההודעה אומרת באיזו שורה.
- העלאה ב-39 מנות של 2,000. הרצה חוזרת בטוחה (upsert על המפתח).
- בסוף: ספירת שורות ובדיקה שכל 20 רכבי הקטלוג נמצאים לפי המפתח המלא עם אותו שווי שימוש.
- `--dry-run`: בדיקה בלבד, בלי העלאה. `--replace`: מוחק קודם את שורות שנת המס, כשמגיע קובץ חדש שהוסרו ממנו דגמים.

## מיגרציה חדשה
קובץ חדש ב-`migrations/` בשם `YYYYMMDDHHMMSS_description.sql`, בדיקה מקומית, ואז `npx supabase db push`.

```bash
uv run --no-project --python 3.12 --with pgserver --with "psycopg[binary]" python supabase/tests/run_local.py
```

## מודל ההרשאות בקצרה
- **כל הכתיבות דרך ה-API** (מפתח סודי, בצד השרת בלבד). הדפדפן רק קורא ומאזין לעדכונים בזמן אמת.
- **עובד** (כניסה אנונימית) רואה רק את השיחות שלו ואת מה שבתוכן.
- **נציג** (`app_metadata.role = rep`) רואה רק את שאלות הנציג, עם הקשר מינימלי. **לא** שיחות, לא שכר.
- **מאגר שווי השימוש** פתוח לקריאה לכולם (נתונים ציבוריים של רשות המסים).
- **טבלאות שיתווספו בעתיד** מתחילות לקריאה בלבד לדפדפן (default privileges), כך שהכלל "כתיבה רק דרך ה-API" לא תלוי בזיכרון של מי שכותבת את המיגרציה.
